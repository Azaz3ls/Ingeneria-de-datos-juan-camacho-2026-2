# Portafolio — Ingeniería de Datos

Repositorio personal para el seguimiento de actividades, prácticas y tareas
del curso de Ingeniería de Datos. Este repositorio funciona como mi
portafolio digital de evidencias durante el semestre.

## 📁 Organización

El repositorio está organizado por **corte académico**, y dentro de cada
corte, por actividad:

```
├── Corte_1/
│   ├── 01_ETL_Crimenes/       # Pipeline ETL (Excel + Python/Colab)
│   └── 02_Fruteria/           # Ejercicio de análisis de datos
├── Corte_2/                   # (próximamente)
└── Corte_3/                   # (próximamente)
```

Cada carpeta de actividad incluye su propio `README.md` con una breve
descripción del ejercicio, los archivos entregados y cómo revisarlos.

## 🛠️ Cómo navegar este repositorio

1. Entra a la carpeta del corte correspondiente (`Corte_1`, `Corte_2`, etc.)
2. Entra a la carpeta de la actividad que quieras revisar
3. Lee el `README.md` de esa actividad para el contexto
4. Los notebooks (`.ipynb`) se pueden ver directamente en GitHub; los
   archivos `.xlsx` deben descargarse para abrirlos en Excel

## ✅ Buenas prácticas seguidas

- Nombres de archivos y carpetas claros y descriptivos
- Commits frecuentes que reflejan el avance real de cada actividad
- Repositorio público para facilitar la revisión del progreso
