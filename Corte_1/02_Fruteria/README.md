# Actividad: Análisis de Datos — Frutería

Ejercicio de registro y análisis de datos de compra/venta (inversión,
precio, ganancia y comprador) organizado por rondas.

## Archivos

| Archivo | Descripción |
|---|---|
| `fruteria_inge_de_datos.xlsx` | Registro de inversión, ventas y ganancias por producto y por ronda |

## Contenido

- **Hoja 1**: registro principal de frutas (inversión, precio, ganancia,
  comprador, total y ronda), con resumen de gasto/venta por ronda
- **Hoja 2**: registro de un presupuesto adicional
- **Hoja 3**: tabla base de inversión y precio por fruta
